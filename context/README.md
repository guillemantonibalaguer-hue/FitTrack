# FitTrack: context del projecte

Aquest directori conserva les decisions útils per continuar FitTrack a les unitats següents. El dossier de la UT1 desenvolupa i justifica l'anàlisi; aquests fitxers en guarden el resum operatiu.

## Com llegir el context

- [Projecte i abast](projecte.md): què és FitTrack, per a qui i què inclou l'MVP.
- [Necessitats i oportunitats](necessitats.md): evidència recollida, límits i oportunitats.
- [Requisits inicials](requisits.md): capacitats, condicionants i criteris de qualitat.
- [Decisions i qüestions pendents](decisions.md): què s'ha acordat provisionalment i què s'ha de validar.

Les decisions són inicials i revisables. No s'han de presentar com a dades de mercat ni com a compromisos d'un gimnàs concret.
