# Decisions i qüestions pendents

## Decisions provisionals acordades

- Continuar amb FitTrack, adaptant la proposta d'UT0 a una aplicació web senzilla.
- Orientar el producte a membres i personal del gimnàs; el gimnàs seria el client previst.
- Usar dos perfils d'usuari per a l'MVP.
- Delimitar l'MVP a consulta d'ocupació, reserves d'activitats i consultes/peticions.
- Fer servir dades simulades per a l'ocupació en aquesta primera versió.
- Considerar el model SaaS com a hipòtesi de negoci, no com a decisió comercial validada.
- Deixar pagaments, accés digital, venda de material, sensors reals i aplicació nativa fora de l'abast inicial.

## Decisions pendents

- Confirmar amb un gimnàs qui actualitzaria les dades i amb quina freqüència.
- Validar si les reserves més importants són de classes, activitats o altres serveis.
- Demanar exemples concrets dels problemes que les persones tenen avui amb consultes i reserves.
- Validar la necessitat d'ocupació amb usuaris de gimnasos de mides diferents.
- Definir si el servei seria gratuït per als membres i com el pagaria el gimnàs.
- Revisar l'abast després de rebre comentaris de la docent o d'un centre col·laborador.

## Estat

Versió inicial preparada per a la UT1; revisable quan hi hagi noves evidències o decisions de l'equip.
